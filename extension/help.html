네이버 쇼핑 수집기 사용 안내

관리 화면에 검색어 JSON 배열을 넣고 수집 시작을 누르세요.

["플래티넘 사료", "강아지 간식"]

검색어당 1~2페이지를 탐색합니다. 2페이지가 없는 경우 다음 검색어로 넘어갑니다. 스크롤과 2페이지 이동 전에는 10~70초, 다음 검색어 전에는 180~600초를 무작위로 기다립니다.

상품이미지는 파일이 아닌 URL로 저장합니다. 업체명은 직접 판매 상품에 표시된 이름이며, 가격비교 상품은 업체명을 비워두고 sellers 배열에 화면에 보이는 판매처들을 저장합니다. 판매가격, 정상가, 쿠폰가격은 각각 별도 필드입니다.

일시정지 후 재개하면 현재 페이지를 처음부터 다시 확인하며 같은 검색어·페이지의 중복 상품을 합칩니다. 다음 검색어 대기 중 멈춘 경우 남은 대기 시간을 이어갑니다. 작업 종료 후에도 결과는 보관됩니다.

CSV와 JSON에는 필터와 관계없이 모든 수집 결과가 포함됩니다. 새 수집은 기존 결과를 다운로드하고 작업 종료 및 결과 비우기를 실행한 뒤 시작하세요.

관리 화면은 닫아도 됩니다. 검색 탭을 직접 조작하지 말고 Chrome과 컴퓨터를 켜두세요. 절전 또는 백그라운드 제한으로 예약된 시간보다 늦게 진행될 수 있습니다. 브라우저를 재시작하면 일시정지됩니다.

접근 제한·보안 확인 화면이나 상품 영역 인식 실패 시 자동으로 멈춥니다. 검색 탭을 직접 확인한 후 재개하세요. 네이버 화면 구조가 바뀌면 extractor.js의 선택자 수정이 필요할 수 있습니다.

결과는 현재 Chrome 프로필에 로컬 저장됩니다. 확장 프로그램을 삭제하면 결과도 삭제될 수 있으니 먼저 다운로드하세요.
