네이버 쇼핑 수집기 사용 안내

서버 연결: 레이어의 서버 연결에서 HTTPS 서버 주소와 접속 토큰을 입력하고 토큰 로그인을 누르세요. 로컬 mnbg-admin은 주소가 http://localhost:8080으로 기본 입력되며 API 경로는 확장이 자동으로 붙입니다. 해당 주소의 사이트 접근을 허용하면 토큰 인증과 검색어 조회 API를 확인합니다. 별도 로그인은 필요하지 않습니다. 서버 연결 확인으로 수집을 시작하거나 작업을 선점하지는 않습니다.

서버 키워드 수집: 서버 키워드로 수집을 누르면 대기 키워드 하나를 받아 수집하고, 결과를 자동 전송한 뒤 다음 검색어 대기 시간만큼 쉬었다가 다음 서버 키워드를 다시 받아옵니다. 대기 중인 키워드가 없으면 완료로 끝납니다. 도중에 멈추려면 작업 종료를 누르세요. 종료 시 그때까지 모은 상품을 전송하며, 전송에 실패하면 로컬 결과를 보관하고 업로드 재시도로 다시 보냅니다. 이미 전송한 결과도 재시도로 다시 보낼 수 있고, 서버는 상품 기준으로 갱신하므로 중복 저장되지 않습니다.

토큰은 현재 Chrome 프로필에 저장하며 수집 페이지·CSV·JSON으로 전달하지 않습니다. 저장한 토큰은 입력란에 다시 표시하지 않고, 같은 주소에서는 입력란을 비워두면 기존 토큰을 사용합니다. 주소를 변경할 때는 토큰도 다시 입력하세요. 설정 삭제는 서버 주소와 토큰만 삭제합니다.

확장 아이콘을 누르면 지금 보고 있는 페이지 오른쪽에 제어 레이어가 열립니다. 아이콘을 다시 누르거나 레이어 오른쪽 위 ×를 누르면 닫힙니다. 페이지를 이동하면 레이어는 사라지며, 수집 중인 검색 탭에서는 자동으로 다시 표시됩니다.

동작 미리보기 ↗에서 스크롤, 무작위 대기, 페이지 전환과 다음 검색어 진행을 볼 수 있습니다. 예시 상품으로 만든 데모이며 실제 수집·저장은 하지 않습니다.

검색 화면만 열기는 첫 번째 검색어의 실제 네이버 페이지를 보여줍니다. 작업을 만들거나 자동 스크롤·상품 저장을 실행하지 않습니다.

실제 수집을 시작하려면 레이어에 검색어 JSON 배열을 넣고 수집 시작을 누르세요. 검색 탭은 같은 Chrome 창에서 열립니다. 수집 탭 보기 버튼으로 움직이는 페이지를 확인할 수 있습니다.

["플래티넘 사료", "강아지 간식"]

JSON 배열 오른쪽에 중복을 제외한 검색어 개수가 표시됩니다. 페이지당 상품은 40개 또는 80개(기본 80개) 중 선택하고, 검색 범위는 1~10페이지 중 마지막 페이지를 선택합니다. 기본은 1페이지라 페이지를 넘기지 않고 한 번에 80개까지 수집합니다. 카테고리 ID는 기본값 50000155이며, 비우면 전체 검색입니다. 스크롤 이동량은 보이는 화면 높이의 50%·85%·100% 중 선택합니다. 한 번의 스크롤은 선택한 거리를 2~4번의 이동으로 나누며, 이동마다 거리(짧게·길게)와 속도(빠르게·느리게)를 무작위로 바꿉니다. 약 30% 확률로 80~180px 위로 잠깐 올라갔다가 다시 내려오고, 한 동작의 순 이동량은 선택한 거리와 같습니다. 이동 전에는 페이지 안에서 마우스 포인터를 1~7번 천천히 움직이는 합성 이벤트를 보냅니다. 실제 운영체제 커서가 움직이지는 않으며, 웹사이트는 이 이벤트가 자동 생성되었음을 구분할 수 있습니다. 다음 페이지가 없으면 해당 검색어의 탐색을 마칩니다.

스크롤·페이지 이동 전 대기의 최소·최대를 5초~5분에서, 다음 검색어 대기는 1~20분에서 선택합니다. 선택한 범위에서 무작위로 기다립니다. 기본값은 1페이지, 페이지당 80개, 화면 85%, 동작 10~70초, 검색어 3~10분이며 카테고리 ID는 50000155입니다. 설정은 시작 전에 선택하세요.

초록색 시작 버튼과 일시정지·재개·종료 아이콘은 한 줄에 있습니다. 각 아이콘에 마우스를 올리면 기능명이 표시됩니다. 진행 상태는 맨 위에 작게 표시하며 작업 중에는 검색어와 설정을 바꿀 수 없습니다.

상품이미지는 파일이 아닌 URL로 저장합니다. 업체명은 직접 판매 상품에 표시된 이름이며, 가격비교 상품은 업체명을 비워두고 sellers 배열에 화면에 보이는 판매처들을 저장합니다. 판매가격, 정상가, 쿠폰가격은 각각 별도 필드입니다.

일시정지 후 재개하면 현재 페이지를 처음부터 다시 확인하며 같은 검색어·페이지의 중복 상품을 합칩니다. 다음 검색어 대기 중 멈춘 경우 남은 대기 시간을 이어갑니다. 작업 종료 후에도 결과는 보관됩니다.

CSV와 JSON에는 필터와 관계없이 모든 수집 결과가 포함됩니다. 새 수집은 기존 결과를 다운로드하고 작업 종료 및 결과 비우기를 실행한 뒤 시작하세요.

레이어는 닫아도 됩니다. 검색 탭을 직접 조작하지 말고 Chrome과 컴퓨터를 켜두세요. 절전 또는 백그라운드 제한으로 예약된 시간보다 늦게 진행될 수 있습니다. 브라우저를 재시작하면 일시정지됩니다.

접근 제한·보안 확인 화면이나 상품 영역 인식 실패 시 자동으로 멈춥니다. 검색 탭을 직접 확인한 후 재개하세요. 네이버 화면 구조가 바뀌면 extractor.js의 선택자 수정이 필요할 수 있습니다.

결과는 현재 Chrome 프로필에 로컬 저장됩니다. 확장 프로그램을 삭제하면 결과도 삭제될 수 있으니 먼저 다운로드하세요.
