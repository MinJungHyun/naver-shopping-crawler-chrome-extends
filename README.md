# 네이버 쇼핑 수집기 Chrome 확장 프로그램

검색어 `string[]`와 페이지·스크롤·대기 설정을 입력받아 네이버 쇼핑 상품 정보를 수집하도록 작성한 Manifest V3 확장 프로그램 초안입니다. 확장 아이콘을 누르면 현재 페이지 위에 뜨는 레이어에서 제어하고, 수집 중인 검색 탭에서는 같은 레이어가 자동으로 표시됩니다. 별도 서버와 빌드 과정 없이 `extension/` 폴더를 Chrome에 로드할 수 있습니다.

## 현재 상태

2026-11-09 기준:

- 실제 네이버 쇼핑 화면에서 상품 카드, 판매처, 가격 필드와 스크롤 후 지연 로딩 구조를 확인했습니다.
- 관리 화면과 오른쪽 레이어 형태의 데모를 Chrome에서 확인했습니다. 320px 너비에서 검색어 개수, 설정 선택, 한 줄 실행 버튼과 간결한 진행 표시를 확인했습니다.
- 입력·설정 검증, 실제 실행 코드의 대기·스크롤·페이지 전환, 가격 추출, 중복 병합, 작업 상태, 레이어 주입과 창 폴백, 데모 모드 격리 등을 다루는 자동 테스트가 통과했습니다.
- **확장 프로그램 설치와 실제 자동 수집은 실행하지 않았습니다. 실제 수집 결과 파일도 없습니다.**
- Chrome에 설치한 상태의 레이어 UI 및 실제 검색어별 수집, 대기, 재시작, CSV/JSON 다운로드를 끝까지 수행하는 검증은 아직 하지 않았습니다.

설치하거나 레이어를 열기만 해서는 수집하지 않으며, **수집 시작**을 눌러야 실제 수집이 실행됩니다. **동작 미리보기**는 예시 상품을 이용하는 시뮬레이션이며 네이버에 접속하거나 실제 수집 결과를 저장하지 않습니다. 실페이지를 검사하는 별도의 분석 전용 모드는 구현하지 않았습니다.

## 구현한 동작

| 항목 | 동작 |
| --- | --- |
| 입력 | 비어 있지 않은 문자열의 JSON 배열. 공백을 정리하고 중복 검색어를 제거 |
| 제어 화면 | 확장 아이콘을 누르면 현재 페이지 오른쪽에 레이어로 표시. 페이지를 이동하면 사라지고, 수집 중인 검색 탭에서는 자동으로 다시 표시. 폭 380px에서 상품은 카드 형태 |
| 실제 화면 미리보기 | 검색 화면만 열기로 첫 검색어의 실제 네이버 페이지를 표시. 작업 생성·자동 스크롤·저장 없음 |
| 진행 관찰 | 검색어·페이지·스크롤 횟수·다음 동작 대기 표시. 검색 탭 좌하단 진행 배지(레이어와 겹치지 않도록), 수집 탭 보기로 현재 검색 탭에 바로 이동 |
| 동작 미리보기 | 예시 검색 화면과 실제 레이어 UI를 나란히 표시. 재생·일시정지·단계 이동·배속 지원 |
| 검색 URL | `https://search.shopping.naver.com/search/all`의 `query`에 검색어, `pagingSize`에 페이지당 상품 수(기본 80), 카테고리 ID를 입력한 경우 `catId`를 지정 |
| 페이지당 상품 | 40개 또는 80개 중 선택. 기본 80개 |
| 카테고리 ID | 선택 입력. 숫자로 된 네이버 쇼핑 카테고리 ID를 넣으면 모든 검색어에 `catId`로 적용. 비우면 검색어 전체 검색 |
| 검색 범위 | 1~10페이지 중 마지막 페이지 선택. 기본은 1페이지라 페이지를 넘기지 않고 한 번에 80개까지 수집. 다음 페이지 링크가 없으면 조기 종료 |
| 스크롤 | 보이는 화면 높이의 50%·85%·100% 중 선택. 한 번의 동작을 2~4번의 이동으로 나누되 짧고 긴 이동, 빠르고 느린 속도를 매번 다르게 합니다. 약 30% 확률로 80~180px 위로 잠깐 올라갔다가 다시 내려오며, 한 동작의 순 이동량은 설정값과 같습니다. 이동 전에는 포인터를 1~7번 움직입니다(합성 이벤트). 숨겨진 탭에서는 애니메이션·포인터 없이 즉시 스크롤 |
| 스크롤·페이지 이동 대기 | 최소·최대를 각각 5초~5분에서 선택. 선택한 범위에서 정수 초 무작위 대기 |
| 다음 검색어 대기 | 최소·최대를 각각 1~20분에서 선택. 초로 환산한 범위에서 무작위 대기 |
| 저장 | 현재 Chrome 프로필의 `chrome.storage.local` |
| 작업 제어 | 일시정지, 재개, 종료, 결과 비우기 |
| 결과 확인 | 상품명·업체명·검색어 필터, 최근 결과 최대 200개 표시 |
| 내보내기 | 전체 결과 CSV / JSON 다운로드. 화면 필터와 관계없이 전체 결과 포함 |
| 오류 처리 | 접근 제한·보안 확인, 상품 영역 인식 실패, 탭 무응답 시 자동 일시정지 |

기본 설정은 1페이지(페이지당 80개), 화면 85% 스크롤, 동작 대기 10~70초, 다음 검색어 대기 3~10분이며 카테고리 ID는 비어 있습니다. 설정은 시작 전에 선택하며 실행·일시정지 중에는 변경할 수 없습니다. 최소값이 최대값을 넘으면 반대쪽 값을 함께 맞춥니다. 선택한 설정은 로컬에 저장하고 시작한 작업의 `job.settings`에 고정합니다. 설정 필드가 없는 기존 작업은 기본값으로 이어갑니다.

상단에는 상태·검색어·페이지·수집 개수를 작게 표시합니다. 배열 입력란의 오른쪽에는 `string[]`와 중복을 제외한 검색어 개수가 표시되며, 시작·일시정지·재개·종료 버튼은 한 줄 아이콘으로 제공합니다.

이미지는 이미지 파일 대신 **URL**로 저장합니다. 일반 판매 상품의 업체명과 가격비교 상품의 판매처 목록을 구분하며, 가격비교 상품의 모든 판매처 상세 페이지까지 방문하지는 않습니다.

## 설치

Chrome 120 이상이 필요합니다. Node.js는 테스트용이며 확장 프로그램 실행에는 필요하지 않습니다.

1. 이 저장소를 내려받거나 클론합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 저장소 루트가 아닌 **`extension/` 폴더**를 선택합니다.
6. 확장 프로그램 아이콘을 누르면 보고 있던 페이지 위에 제어 레이어가 열립니다. 아이콘을 다시 누르면 닫힙니다.

기존 버전을 설치해 두었다면 `chrome://extensions`에서 이 확장 프로그램의 새로고침 버튼을 눌러 적용하세요. 이전 작업은 저장된 설정이 없던 항목을 새 기본값(1페이지·80개·카테고리 없음)으로 이어갑니다. `chrome://` 페이지나 엄격한 CSP를 쓰는 페이지처럼 레이어 삽입이 막히면 대시보드가 작은 팝업 창으로 열립니다.

먼저 검색 화면만 보고 싶다면 배열을 입력하고 **검색 화면만 열기 (수집 안 함)**를 누르세요. 첫 번째 검색어의 실제 네이버 페이지가 같은 창의 탭에 열리며 자동 스크롤이나 상품 저장은 실행하지 않습니다. 실제 수집을 원할 때만 **수집 시작**을 누릅니다.

```json
["플래티넘 사료", "강아지 간식"]
```

레이어를 닫아도 검색 탭에서 작업이 계속되도록 구성했습니다. 수집 시작 시 현재 Chrome 창에 검색 탭을 열고 같은 탭에서 검색어·페이지를 바꿉니다. 본문에서 사람처럼 드르륵 내려가는 스크롤과 함께 움직이는 포인터를 보면서 레이어에서 상태를 확인할 수 있습니다. 검색 탭과 Chrome은 열어두세요. 일시정지 후 재개하면 현재 페이지를 처음부터 다시 확인하고 중복 항목을 병합합니다. 다음 검색어를 기다리던 중 멈추면 남은 대기 시간을 이어갑니다. 브라우저 또는 확장 프로그램 재시작 시 일시정지하며 수동으로 재개해야 합니다.

새 수집을 시작하려면 기존 결과를 다운로드한 뒤 작업을 종료하고 결과를 비우세요. 실행 중이거나 일시정지 중인 작업의 결과는 비울 수 없습니다.

## 수집 데이터

| 필드 | 내용 |
| --- | --- |
| `keyword`, `page`, `rank` | 검색어, 페이지, 추출 시 페이지 내 순서 |
| `productId`, `productName` | 상품 ID, 상품명 |
| `imageUrl` | 지연 로딩 후 확인한 이미지 URL |
| `sellerName`, `sellerUrl` | 일반 판매 상품의 업체명과 링크. 미표시 시 빈 문자열 |
| `price` | 표시 판매가격. 가격비교 상품은 표시 최저가격 |
| `couponPrice`, `originalPrice` | 별도 표시된 쿠폰가격, 정상가. 미표시 시 `null` |
| `shipping` | 화면에 표시된 배송비 문자열 |
| `productUrl` | 검색 결과의 상품 링크. 네이버 리다이렉트 링크일 수 있음 |
| `isAd` | 명시적인 광고 메타데이터 또는 광고 카드·라벨 기준 판별 |
| `productType` | 판매처 목록이 있는 경우 `catalog`, 그 외 `single` |
| `sellers` | 가격비교 카드에 표시된 판매처의 `{ name, price, url }` 배열 |
| `sourceUrl`, `collectedAt` | 검색 페이지 URL과 추출 시각(ISO 8601) |

JSON은 작업 정보와 `items` 배열을 포함합니다. CSV는 UTF-8 BOM을 포함하며, `sellers`는 셀 안에 JSON 문자열로 저장합니다. 두 형식 모두 상품 데이터는 동일하며 CSV 열에는 `sourceUrl`이 포함되지 않습니다. 동일 검색어·페이지의 상품 ID(없으면 링크 또는 상품명)와 광고 여부를 기준으로 중복을 병합합니다. 검색어 또는 페이지가 다르면 별도 결과로 유지합니다.

## 개발 및 검증

```sh
nvm use
npm ci
npm test
```

Node.js 22.16.0 이상을 사용합니다. 테스트 의존성은 `linkedom`이며 확장 프로그램에 런타임 패키지를 설치할 필요는 없습니다.

화면만 확인하려면 Python 3이 설치된 환경에서 실행합니다.

```sh
npm run preview
```

[로컬 미리보기](http://127.0.0.1:8765/dashboard.html)는 수집 시작 버튼이 비활성화되며 실제 수집을 실행할 수 없습니다.

[동작 데모](http://127.0.0.1:8765/demo.html)에서 검색 화면과 오른쪽 레이어를 함께 볼 수 있습니다. 레이어의 탐색·대기 설정을 바꾼 뒤 **데모 재생**하거나 **다음 단계**, 아래 단계 버튼을 이용하세요. 선택한 설정은 데모의 페이지 수와 스크롤·대기 예시에도 반영됩니다. 시간만 선택한 배속으로 압축하며 실제 수집을 실행하거나 실제 설정을 저장하지 않습니다. 레이어의 미리보기 링크에서도 이 페이지를 열 수 있습니다. 데모의 CSV/JSON 내보내기는 비활성화되어 있고 모든 상태는 메모리 안에서만 유지됩니다.

## 권한과 한계

- 호스트 권한은 `https://search.shopping.naver.com/*`에 한정합니다.
- `storage`, `unlimitedStorage`는 로컬 결과 저장, `alarms`는 다음 검색어 대기와 무응답 감지, `scripting`은 페이지에 제어 레이어(`<aside>`)를 넣고 수집 스크립트를 재주입하는 데, `activeTab`은 아이콘을 누른 현재 탭에 레이어를 넣는 데 사용합니다.
- 외부 서버로 결과를 전송하는 기능은 없습니다. 관리 화면에서 상품 이미지를 표시하면 해당 이미지 URL로 요청합니다.
- 네이버 화면 구조가 바뀌면 `extractor.js` 및 페이지 링크 선택자의 수정이 필요할 수 있습니다.
- 백그라운드 탭 제한, 절전, 시스템 부하로 실제 대기가 선택한 시간보다 길어질 수 있습니다. 정확한 실행 시각을 보장하지 않습니다.
- CAPTCHA나 접근 제한을 우회하지 않습니다. 자동으로 멈춘 뒤 사용자가 검색 탭을 직접 확인해야 합니다.
- 수집 데이터는 Chrome 프로필에 저장됩니다. 확장 프로그램 삭제 전에 필요한 결과를 다운로드하세요.

구현 시 참고한 공식 문서: [Chrome Scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting), [Chrome 확장 프로그램 서비스 워커 수명 주기](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle), [Chrome Alarms API](https://developer.chrome.com/docs/extensions/reference/api/alarms).
